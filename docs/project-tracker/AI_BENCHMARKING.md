# AI Clip Ranking Benchmark

## Why this exists

Clip Finder now has transcript-derived proposals, media-event proposals, and a deterministic multimodal reranker. The reranker is a transparent baseline, not a trained highlight model. Audio energy and visual motion are imperfect proxies for interesting moments, so quality claims must be measured against human-labelled source videos.

## Run it

From the repository root, create a JSON manifest of your own reviewed labels and run:

```powershell
python -m ai.services.benchmark path\to\your-labels.json --top-k 10 --iou-threshold 0.5 --output benchmark-results.json
```

The command compares current candidate scores with scores after deterministic reranking. It reports precision/recall and temporal IoU per video, then averages recall per genre and across genres. Each case represents one source video; timestamps are never matched across separate videos.

## Manifest contract

```json
{
  "version": 1,
  "cases": [
    {
      "id": "unique-source-video-id",
      "genre": "gaming",
      "predictions": [
        {
          "start": 120.0,
          "end": 146.0,
          "score": 84.0,
          "features": {
            "audioEnergy": 0.7,
            "visualChange": 0.6
          }
        }
      ],
      "groundTruth": [
        {
          "start": 124.0,
          "end": 143.0
        }
      ]
    }
  ]
}
```

- `id` must uniquely identify a source video.
- `genre` should use a consistent label such as `gaming`, `podcast`, `irl`, `tutorial`, `sports`, or `other`.
- `predictions` are candidates from the pipeline, including their scores and optional ranking features.
- `groundTruth` contains moments reviewed and labelled by a human. It must not be generated by the same ranking system being evaluated.
- Times are seconds from the start of the source video. All intervals must have finite values, start at or after zero, and end after start.
- Keep a held-out set of videos separate from any tuning set. Include multiple creators and different recording conditions per genre.

## Reading results

A prediction matches a ground-truth moment when temporal intersection-over-union (IoU) reaches the configured threshold. Precision@K uses K as its denominator; recall@K is the fraction of labelled moments matched by the selected top-K predictions. One prediction cannot claim multiple ground-truth moments.

The report includes both the original score ordering and the deterministic reranked ordering. If reranking improves one genre but hurts another, do not hide the regression by reporting only the overall average. Use the per-video results to identify failure modes.

## Current limitations

- No labelled dataset is checked in; this repository therefore makes no measured claim that the reranker improves clip quality.
- These metrics evaluate temporal overlap, not whether a clip is funny, useful, coherent, safe, or likely to perform well on social platforms.
- Temporal boundaries and labels need human review. Use a representative, held-out sample before changing ranker weights or describing improvements as general.
